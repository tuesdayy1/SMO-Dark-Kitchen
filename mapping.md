# Маппинг бизнес-домена на СМО

> Текстовая копия исходного DOCX для удобства просмотра в GitHub. Исходный документ сохранён в `docs/originals/`. Содержательные изменения не вносились.

22 вариант Аслямов М. Р. 5130904/40106

| Элемент СМО | Сущность бизнес-домена | Назначение |
| --- | --- | --- |
| Источник | Цифровые витрины ресторанных брендов | Формируют электронные заказы на приготовление блюд. Источники бесконечные (ИБ); интервалы между заказами распределены равномерно (ИЗ2). Приоритеты источников зависят от условий SLA брендов (например, И1 > И2 > И3). |
| Заявка | Заказ на приготовление блюда | Один запрос на готовку. Содержит уникальный идентификатор чека, номер ресторанного бренда (источника), рецептурные модификации и время поступления. |
| Буферная память | Экран предзаказов кухонного цеха | Хранит заказы, ожидающие приготовления. Занимает места последовательно с начала очереди. При уходе чека к повару вся оставшаяся очередь автоматически сдвигается на одну позицию вперед, освобождая место в конце (Д1ОЗ2). |
| Прибор | Повар-универсал технологической линии | Выполняет термическую обработку, сборку и упаковку блюда. Одновременно выполняет одну заявку. Время приготовления имеет экспоненциальное распределение (ПЗ1). |
| Диспетчер постановки | Программный алгоритм агрегации чеков | Получает заказы и ставит их в конец очереди буфера со сдвигом (Д1ОЗ2). Если все повара и буфер заняты, вытесняет (аннулирует) самую последнюю по времени поступления в буфер заявку (Д1ОО4), записывая новую на её место. |
| Диспетчер выбора | Программный алгоритм распределения задач | Выбирает из очереди один чек наиболее приоритетного ресторанного бренда, а среди его чеков — последний поступивший (Д2Б4). Передает его свободному повару, найденному по кольцу от указателя приборов УП (Д2П2). |
| Отказ | Аннулирование чека при перегрузке | При переполнении удаляется самая «свежая», последняя из уже находящихся в буфере заявок (Д1ОО4). Она отменяется без траты продуктов; отказ засчитывается её бренду-источнику. Новая заявка занимает освободившееся место. |
| Обслуживание | Приготовление и сборка блюда | Повар берет чек, готовит блюдо согласно рецепту и передает его на упаковку. После завершения повар освобождается для следующего заказа. Начатый процесс готовки не прерывается. |
| Выход из системы | Готовое блюдо или аннулированный чек | Заказ покидает систему после полного приготовления либо после вытеснения из буфера в момент переполнения. Результат и время выхода фиксируются для статистики |
